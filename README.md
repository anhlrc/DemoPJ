# 3D Virtual Museum - Bảo Tàng Ảo 3D

Dự án Triển lãm & Bảo tàng Ảo 3D tương tác web (HTML/CSS/JS + Three.js).

## Tính năng
- Tham quan không gian 3D tương tác.
- Xem chi tiết các mẫu vật 3D (Bình đồng, Cảm gặp, Bao da, Camera...).
- Tải và hiển thị mô hình 3D trực tiếp trên trình duyệt.
